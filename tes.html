Apa Itu Algoritma?

Algoritma adalah urutan langkah-langkah logis dan sistematis untuk menyelesaikan suatu masalah. Algoritma membantu kita berpikir secara terstruktur sebelum membuat sebuah program.

Apa Itu Pemrograman?

Pemrograman adalah proses membuat instruksi menggunakan bahasa pemrograman agar komputer dapat menjalankan tugas tertentu sesuai dengan perintah yang diberikan.

Contoh Program C++

Berikut adalah contoh program sederhana menggunakan bahasa pemrograman C++ untuk menampilkan tulisan Hello World. 

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!";
    cout << "\nSelamat Belajar C++!";

    return 0;
}
